## 配置兼容

1. 在删除供应商 sealed 子类前，先实现并运行兼容专项，确认完整 Settings JSON 可以过滤旧类型。
2. 新增 ProviderListCompatSerializer：只过滤 providers 数组内 `type == "local_llamacpp"` 的对象，再交给正常 sealed-class 反序列化。
3. 同时接入 Settings.providers 注解和 SettingsFields.PROVIDERS 的独立 encode / decode。
   应用 DataStore 是逐字段保存的，只改注解不足以覆盖实际加载；完整备份和逐字段存储必须共用兼容器。
4. 其他未知供应商类型、损坏的 discriminator 和非数组配置仍按正常方式报错，不吞异常、不回退重置全部设置。
5. Settings 只删除 enableMemoryFusion / enableLocalGpu。旧磁盘键 enable_memory_fusion / enable_local_gpu 保留但不再识别。
   JsonInstant.ignoreUnknownKeys 仍开启，因此旧备份中的两个布尔字段也能忽略。
6. 同时删除仅供本地模型使用的 Model.chatTemplate；旧模型 JSON 的该字段按既有 unknown-key 策略忽略。
   VIDEO 能力枚举、历史视频消息与其他模型参数保留。
